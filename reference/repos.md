# 仓库清单（repos）

本工作流涉及的**你的业务代码仓库**清单【模板占位：填你的仓库】。**人类主写，按任务增量补全**；每条仓库**打标签**便于 grep 查询。AI 接到涉及代码的任务时，先查本文件定位要动哪个仓库，再在对应 `src/<namespace>/<repo>/` 工作。

> 冷启动：本文件初始为空，随首个 `#feat` 任务由人类填写第一条。`src/` 中尚无任何仓库时，`story` 流只能做设计/计划（`design.md`/`plan.md`），不能写真代码。
