# exps 经验层说明（判断型专属暂存区）

> 用法：**沉淀前**过 §2 判型（前三档不进本层）；**检索**走 [INDEX.md](./INDEX.md) 热层（或命令失败时 `.tools/exp-lookup.py`）；**再犯计数**走 [TRIGGERS.md](./TRIGGERS.md)。机制真源 = [WORKFLOW §2.4](../WORKFLOW.md)，本文件只讲层定位与文件分工，不复写判据全文。

## 1. 本层定位

exps 收纳**判断型**经验——只能靠检索命中、暂无更硬拦截通道的教训。它是**暂存区**而非终点：教训在本层等再犯计数验证（计数 2 标候选 / 3 必毕业），毕业时升格到不依赖人记得查的拦截通道。理想态下留在本层的，都是「还没被证明需要升格」的。

## 2. 什么不进本层（入口判型四档）

| 档 | 判据 | 载体 |
| --- | --- | --- |
| 机检型 | 机器可判定特征 | workspace-check 分区 / `.tools` 校验（教训写成断言，零人工） |
| 场景型 | 高风险动作前可拦 | 场景触发点（skill 检查项 / 规则文档触发节）+ INDEX「场景」列 |
| 路由型 | 有任务语义路由点 | 对应 skill 检查清单（任务启动即加载） |
| 判断型 | 只能靠检索命中 | **本层** |

判据全文见 WORKFLOW §2.4「沉淀判据卡」④；毕业时的升格路径见同节「坑条目毕业升格判据」。

## 3. 文件分工

| 文件 / 目录 | 职责 |
| --- | --- |
| [INDEX.md](./INDEX.md) | 热层检索面：一行索引（关键词现象词 + 解法词双轴、场景列），默认只读它 |
| [TRIGGERS.md](./TRIGGERS.md) | 再犯计数台账：一行一触发，「触发」= 同类问题再发生（非被引用），毕业判定数据源 |
| [ARCHIVE_INDEX.md](./ARCHIVE_INDEX.md) | 已毕业（留档）条目极简索引 |
| `<主题>/<条目>.md` | 条目正文（判断型专属） |

## 4. 毕业速览

首次沉淀 = 计数 1；再犯确认计数 2 → INDEX 标**毕业候选**；3 → **必须毕业**：内容迁走去向（脚本 / 场景触发点 / skill 清单 / AGENTS 心法一句）为**唯一真源**，源条目同步移除该内容（禁副本驻留）。发现引擎 = 命令失败 / 异常输出先跑 `.tools/exp-lookup.py` 再深查根因（AGENTS「终端操作 · 错误驱动召回」）。

## 5. 存量治理

存量按增量收编：再犯时迁移合并 / 检索命中消费时顺带判型 / 阶段回顾毕业清单顺带判型——不设主动重整批（存量已按判型卡准入，新条目入口即分流）。
