# 经验沉淀索引（exps/）

> `exps/` 的一句话索引（热层）：默认只读本文件，命中再读正文。按主题归档（`<主题>/<经验名>.md`）；**合并优先于新增**，增改下线须同步本文件；治理规则见 [WORKFLOW.md §2](../WORKFLOW.md)。
> 新增关键词**必含现象词 + 解法词双轴**（现象词 = 现场报错/缺陷关键词，解法词 = 技术栈/工具/动词），「读了没用」条目由度量触发改写。「场景」列标拦截场景（build/install/release/migrate/push 开放集；存量不强补，消费时顺带补标）。
> 再犯计数走 [TRIGGERS.md](./TRIGGERS.md) 台账，「毕业去向」列只作人类界面标记；留档毕业内容已全被去向吸收的条目移行 [ARCHIVE_INDEX.md](./ARCHIVE_INDEX.md)，仍承载 Why/判例的留档条目驻本表（见 WORKFLOW §2.4「毕业即移行」）。
