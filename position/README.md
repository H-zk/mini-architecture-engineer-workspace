# Position — 工作区定位基准

> 本文件是工作区的**定位基准**：我是谁、为什么存在、不做什么。**每次与外部对象对比、每次重大机制更新前先对照本文件**——发现偏移（借鉴会改变定位/初心）→ 停下评估、先过操作者裁决。定位变更仅由操作者定。

## 我是谁

1. **本质：人机协作工作区模板**——方法论与业务分离的脚手架：接入任意业务领域，按 SOP 快速上手、放大操作者产能；多实例之间互鉴产生演化。
2. **现状：单操作者实例**——架构工程师的工作区（业务领域见 [AGENTS](../AGENTS.md) 模板占位），承载需求开发、CASE 排查、技术咨询、需求调研、工作区迭代五类任务。
3. **形态：提示词工程**——用规则与提示词资产（AGENTS/WORKFLOW/skills/门禁状态机）驱动 AI 行为。

## 初心（为什么存在）

1. **方法论可复制**：机制设计保持业务与方法论分离——业务知识进 `notes/`、业务代码仓进 `src/`（clone 集合，不进本仓 git），方法论进 WORKFLOW/skills/流程资产。
2. **业务落地为本**：业务任务是主业，治理（工作区优化）是手段不是目的。
3. **人机同行者，知识流双向**：人类给目标、做决策，AI 分析、执行，双方互相验证；知识不只沉淀给 AI 复用，也反哺操作者。
4. **经验是副产品**：任务收尾把可复用结论沉淀 `exps/`/`notes/`，让下次更快。

## 不变原则（重大更新不得偏移）

- **机制须被现实召唤**：宁可晚进、不早进——为不存在的需求建机制是过早优化。
- **单一真源 + 防膨胀**：机制细节一处真源，他处一句摘要 + 指针；顶层文档不承载任务产物。
- **业务 > 治理**：治理类任务占比持续超过业务类 = 偏移信号。
- **安全红线最高优先级**：上下文洁净区、凭证不读取不输出、生产边界（全文见 [AGENTS](../AGENTS.md)「安全红线」）。

## 边界（不做什么）

- 不追求通用 agent 框架的完备性——以「单操作者快速上手业务并放大产能」为目标复制，不为通用而通用、不为大而全堆机制。
- 不为对比而对比：外部借鉴先过「适配而非照搬」+ 本基准对照。
- 不脱离人机分工：AI 不取代操作者的方向裁决权。

## 对比体系（统一入口）

对比参照对象两类 + 记录一处，流程真源 [`colleague-kb-synthesis`](../.agents/skills/colleague-kb-synthesis/SKILL.md)：

- [colleague.md](./colleague.md) — **同事库/外部工作区**登记 + 同步记录（对比 = 工作流范式 + 知识侧重双维度）
- [open-source.md](./open-source.md) — **开源参照对象**登记 + 对比记录（锚定 latest stable release tag；对比 = 架构/范式单维度）
- [compare/](./compare/) — 每次对比记录，命名 `YYYY-MM-DD-vs-<对象>.md`

**对比前**：同步最新仓库、锚定基线（同事库 pull/浅克隆 / 开源项目 release tag）。**对比后两轨分流**：需立即优化 → 建对应工作区任务；有价值待观察 → `BACKLOG.md`。
