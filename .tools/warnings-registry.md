# 机检在册豁免台账（warnings-registry）

> workspace-check warning 分诊真源：表行命中 = 该 warning 从待办池移入「在册豁免」分桶（不数入 warnings、不逐条刷屏）；豁免 ≠ 无害，
> 是**有归属、有理由、有复核期**的知情在册——复核期到点未消化即处置台账行（消化 = 修复后删行 / 复核期滚动）。
> 匹配口径：行以「组前缀:」开头 且（文件 = `*` 表全组，或文件路径出现在告警行内）。
> 机检消费（warnreg 分区：按本表过滤 warnings 输出）随工具批后批接入——接入前本表为人工分诊台账，登记行须自查复核期。
