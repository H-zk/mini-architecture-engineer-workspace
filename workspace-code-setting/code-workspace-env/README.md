# code-workspace-env（worktree 环境文件铺装源）

各项目本地开发所需、**不进 git 的环境文件**按仓库存放于本目录（`<仓库名>/` 子目录），生成器铺装时按下述映射复制到各 worktree 目标位置；目标已存在同名文件**跳过不覆盖**。

## 目录映射【模板占位：按你的仓库逐行落填】

一行一条映射（写法见下方注释示例；注意：非注释行出现「仓库名 + 箭头 + 路径」形态即被当作映射解析，说明文字勿带此形态）：

```text
# 示例（删掉本行后按实际落填）：
# my-repo => my-repo/config/local.yml
```

> 本文件是映射数据源（影响铺装行为），计入模板集 hash——改映射才会被 `--check` 检出。映射为空时生成器跳过 env 铺装。
