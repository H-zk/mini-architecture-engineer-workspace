# plainness-check（AI 平实度终检）

> 四层分工（各层不动，本 skill 只补流程编排层）：

| 层 | 载体 | 管什么 |
| --- | --- | --- |
| 写作纪律 | AGENTS「平实度写作规范」五条 | 每次写文档生效的常驻规则 |
| 数据真源 | [`.tools/plainness-lexicon.md`](../../../.tools/plainness-lexicon.md) | 判据词表 + 使用协议（自包含，数据区消费者免 skill 依赖） |
| 机检 | workspace-check `plainness` 分区 | 结构四指标（单行/表格行/散文段/括号嵌套，warning 档）；词表字词级机检联动后批接入 |
| 执行流 | 本 skill | 何时检、按什么顺序、怎么收口 |

## Steps

1. **对象判读** → 定受众档与语域。
   - 受众档：人读（裁决呈报 / 报告类）跑全流程；混读 / 机读档只跑机检结构级，不做人读字词判读。
   - 语域（真源 = 词表使用协议「语域两档」——清单与豁免判例以词表为准，此处不复写防漂移）：改写方向随语域定，**口语化只属口语体**（备答稿 / 讲稿，标准 = 开口照答念出来不露馅）；书面稿的改写方向 = 精确与信息密度，不往口语改。
2. **机检先行** → `python .tools/workspace-check.py --section plainness`（全量）或 `--task <任务>` / `--paths <文件>`（聚焦）拿结构级命中清单；词表字词级四检测的机检联动未接入（后批接入），由步骤 3 词表判读人工承载。告警三分处置：真文风问题 → 修；机制术语遗传（报告继承工作区机制词）→ 豁免登记 `.tools/warnings-registry.md`（组前缀 `AI 味`）；结构超限 → 拆行拆段。
3. **词表判读** → 按词表逐类扫：十五类（第 15 类只对外文体；第 14 类列举型括号豁免）+ 结构层四判据 + 豁免判例行。同会话先写分析稿再写对外稿时第 15 类必扫（语境外溢高发路径）。
4. **选双模式** → 仅诊断（机制文档 / 结论类：标命中项与位置，不改文）或改写稿（草稿类：原句 → 改句对照，人工采纳）；判据 = 词表使用协议。
5. **分级收敛** → 分级（轻度 / 中度 / 重度）与收敛规则（上限三轮、连续一轮无新改动即停）= 词表使用协议「分级处置」，以其原文为准（终检必读，不复写阈值）。
6. **残留项说明** → 哪些命中保留及理由（豁免判例口径）；机器告警豁免同步登记 registry。
7. **可选 subAgent 盲检** → 主会话改完后独立复核，配方 = [references/blind-review.md](./references/blind-review.md)（不传主会话结论 + 前台跑 + 对照场景 digest 确定性盲标）。

## Outputs（终检产物形态，字面示例）

- **改写稿**（改写模式，原句 → 改句对照，人工采纳）：

  ```text
  | 位置 | 原句 | 改句 | 类别 |
  | report.md:14 | 未来将继续深耕该方向 | （删——结尾无信息） | 公式化结尾 |
  ```

- **残留项说明**（终检收口必带：哪些命中保留及理由）：

  ```text
  残留：report.md:21 「闭环」×3——本仓机制术语遗传非文风问题，已登记 warnings-registry（AI 味组）。
  ```

- **盲检输出**三分格式示例见 [references/blind-review.md](./references/blind-review.md)。

## 红线

- **只报命中不判毒**：分数 / 计数只做线索，不做「这是 AI 写的」判定——命中可验证，「AI 写的」判定不可验证且不可申诉。
- **事实保护优先**：数字 / 术语 / 专名 / 立场措辞原样保留；改后复核数字未漂移——改写损伤事实则终检负收益。
- **禁检测对抗用途**：不用于规避 AI 文本检测器的改写——该用途与事实保护正交且不可承诺效果。
- **零复写**：词表判据与协议只在词表一处，本 skill 只编排不搬运；词表演进走其「来源与版本」节——复写必漂移。
