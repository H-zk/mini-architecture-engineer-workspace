# 盲检配方（subAgent 独立复核 + 对照盲评）

> plainness-check 第 7 步执行细则。两形态：单稿盲检（独立复核）与对照盲评（两版择优）。判据输入 = `.tools/plainness-lexicon.md`（词表十五类 + 结构层四判据 + 语域两档）。

## 一、单稿盲检（subAgent 独立复核）

- **prompt 三要素**：① 判据清单指针（词表路径 + 结构层 + 语域档位）——不给主会话的检查结论与已修清单，独立性即价值；② 产物路径直读；③ 输出三分格式 = 确认已修（逐类点名）/ 疑似命中（原文位置 + 类别 + 建议）/ 豁免建议（理由）——疑似与豁免留裁决，不自动落。字面示例：

  ```text
  确认已修：自查标签类——「（实测）」×2 已删注。
  疑似命中：qa.md:38 「分流到备答二区」——机制自造语（第 15 类），建议「拆成第二条备答」。
  豁免建议：等号箭头记号（A → B）——备答稿面设计目的，口语体记号豁免。
  ```

- **前台跑**：盲检类 subAgent 一律前台跑（后台跑偶发长时间无进展，同 prompt 前台数分钟收口）。
- 事实与数字零变动是前提；盲检发现的事实类问题转事实核查流，不走改写。

## 二、对照盲评（两版择优，digest 确定性盲标）

改写稿要裁决「改后是否更好」时用。四条：

1. **条件重标**：两版匿名化为 A / B；judge prompt 只见标号与正文，不见哪个是原稿 / 改稿、不见改动说明。
2. **确定性盲标**：A / B 与原稿 / 改稿的映射由内容 digest 决定（如 sha256(原稿 + 改稿 + 轮次) 首字节奇偶：偶 = 原稿为 A，奇 = 原稿为 B）——同输入必同盲标，评审可复现审计；禁随机源（不可复现）。
3. **判分所见分离**：judge 问卷只含质量维度（如：哪版抓得住重点 / 哪版更可信 / 事实保留是否完整），不含裁决条件与发布门——judge 结论与准入判定分开。
4. **结果解读**：双题同选一版才下结论；分歧即「无显著差」，按成本低的版本走。
