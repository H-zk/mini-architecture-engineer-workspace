# 任务全景图配方（panorama.html，审核辅助产物）

> 架构型任务进入人类审核时的可视化辅助配方——解决「多场景壳/多层接线/多源数据流/新旧开关类任务 md 产物集复杂度高、入口难读」的审核负担。简单任务**不为它造全景图**；默认形态仍是会话内展示（Mermaid/表格内联优先）。产出物 = 任务目录 `panorama.html`，随任务生命周期保留。
> provenance：基于 v1 sprint-20260827 提炼（tag c199e14），脱敏重写、实例通用化。

## 触发判定

- **触发**：架构型任务进入人类审核（多场景壳 / 多层接线 / 多源数据流 / 新旧开关类），或操作者明确要一份可视化全景。
- **不触发**：简单任务；会话内 Mermaid/表格能说清的。

## 生成纪律（硬约束）

1. **照 worktree / git 实测，不照任务 md 抄**：文件清单用 `git status`/`ls` 实测；数据流、接线逐处回代码核实——任务 md 可能滞后，md 与代码冲突**以代码为准并回报操作者**（全景图兼任文档漂移检测器：源仓首例顺手核出 3 处文档漂移）。
2. 单文件自包含 HTML：无外链、无外部脚本。
3. **不自动打开浏览器**，只报文件路径。
4. 真实文件名、真实数据；桌面/移动自适应。

## 五段固定结构

1. **分层架构**：每文件一句话职责（真实文件名）。
2. **端到端数据流**：一个代表场景走完整链路（编号步骤 + 文件 + 代码锚点）。
3. **多源/多状态差异**：每源一卡。
4. **开关与接线**：切换点逐处列出。
5. **文件树全景 + 边界提醒**：新增/修改分色、分期边界、红线注记。
