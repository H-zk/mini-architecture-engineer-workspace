# workspace-kanban（会话内任务看板）

> 看板是「扫描 → 分诊 → 建议 → 排版」的会话协议，服务四件事：**开工选择**（现在该动哪个）、**全景地图**（全部未归档任务一眼扫完）、**风险雷达**（什么在烂掉）、**单卡接手**（这事到哪了）。会话结束投影即消失。真源 = [AGENTS](../../../AGENTS.md) 任务体系（CURRENT frontmatter），出入以真源为准。

## 一、三红线（最高优先，覆盖一切便利）

1. **零新状态**：不建账本、不缓存、不落常驻快照（temp 一次性件例外见红线 2）；唯一真源 = 五根 CURRENT frontmatter + temp/todo.md + 交接卡 + BACKLOG + WORKFLOW frontmatter 迭代号。「现状靠 grep 算出来、不存出来」。
2. **零新载体**：不出 HTML、不落文件、不起服务；操作者点名要快照时才落 temp 一次性 markdown（不进 git，用完即清）。
3. **零写入**：看板只读（例外 = 红线 2 操作者点名的 temp 一次性快照）；发现状态滞后/漏登记只标注不修（修复走任务流门禁，可顺带提议）。

## 二、扫描配方（唯一配方，统计与开工汇报同源）

```bash
for d in story/*/ case/*/ tech/*/ research/*/ workspace-optimize/*/; do
  [ -d "$d" ] || continue
  c="$d/CURRENT.md"
  if [ ! -f "$c" ]; then echo "ORPHAN|$d"; continue; fi
  echo "$(grep -m1 '^status:' "$c" | sed 's/status: *//')|$d\
|$(grep -m1 '^blocker:' "$c" | sed 's/^blocker: *//')\
|$(grep -m1 '^next:' "$c" | sed 's/^next: *//')\
|$(grep -m1 '^updated-at:' "$c" | sed 's/^updated-at: *//')\
|$(grep -m1 '^sprint-version:' "$c" | sed 's/sprint-version: *//')"
done
```

补充源（并行取）：todo.md 未勾项；交接卡「后续待办」节（存在才读）；`git status --porcelain | wc -l`（未提交规模）。类别由任务所在根目录继承。根级 `archive/` 不在 glob 内、天然不扫。

**快照时效（状态断言必现扫）**：看板与任何单卡状态回答都是「扫描时点的快照」——同会话存续期间，并行会话或操作者可能已改动任务状态（收官、翻态）。操作者问任一任务状态（含看板出图后的追问）时，先重读该任务 CURRENT frontmatter 再作答，**禁沿用本会话早前扫描口径**；确需引用旧看板结论时必须带「截至 MM-DD HH:MM」。

## 三、分诊（顺延折叠 + 两个维度 + 一个时效）

- **顺延折叠（先于分诊）**：CURRENT `blocker` 含「顺延至下迭代／等下迭代」语义且锚有操作者裁决/指示 → 记**顺延单**，看板只显示数量不给明细（操作者问「下迭代／顺延单」才展开）：不进 ①②③④、不参与卡点三分与静默统计；④ 计数类（如对外欠账数）可含其笔数但不给单卡明细。计数落两处 = 头行计数行 + ③ 表后一行。
  - 折叠有时效：blocker 含顺延语义且该任务 `sprint-version` 已等于 WORKFLOW frontmatter 当前值（掉落改标后 = 顺延目标迭代已开始）→ 转**顺延到期组**展开（③ 表后单列小节 + ② 聚合一行「定时机：顺延到期 N 张待确认开工」），不再折叠；`sprint-version` 落后 WORKFLOW 当前值 = 掉落改标遗漏（回顾未收口）⚠ 标出待查。语义存疑（无下迭代字样或无裁决锚）宁展开勿折叠。
- **卡点三分**（主排序维度，按「卡在谁」）：**你** = blocker/next 含操作者闸门语义（等确认/待审核/等裁决/等授权/放行/定时机/终审）；**外部** = 团队/运营/客户/验证资源/预发等第三方等待（含全部验证中）；**AI 可推** = blocker 无且 next 是可执行动作。
- **类别 = 工作流标签**（可见属性，不参与排序，**不自造类别词**）：`#feat`（story 根）／`#case`／`#tech`／`#research`／`#workspace-optimize`——直接用标签词汇；无标签零散工作不立项，故任务目录天然都在标签内。
- **静默**：updated-at 距今天数；>7 天标 ⚠（是「未动」时长，不是状态时长，如实标注）。

## 四、输出规范（四段 + 尾注；全 markdown 表格，禁压缩名单）

**头行**：`# 工作区看板 · MM-DD HH:MM · sprint <WORKFLOW frontmatter sprint-version（占位未定则省）>` + 一行计数（未归档 N〔含顺延下迭代 d，不展开；含已完成待归档 h，仅计数不显示〕｜卡你 x｜等外部 y｜AI 可推 z｜静默>7天 w｜未提交 F；x+y+z 只数可见活跃单 = N−d−h）。

**定期项提醒（并入 ④ 风险雷达）**：仅风险项进 ④——命中下表判据（⚠）或到期边缘（距判据线 ≤1 天）的定期项一行一条（项｜节奏｜上次｜距今），已跑/未到期不显示（健康态零噪音）；全部扫描时点现算、零新状态。节奏与数据锚（节奏戳字段未接入——锚用自然锚，接入节奏戳后切换）：

| 定期项 | 节奏 | 上次锚（数据源） | 提醒判据 |
| ---- | ---- | ---- | ---- |
| skill 市场巡检 | 14 天内一次 | workspace-optimize/ 下最近巡检任务目录基名日期 | >14 天 ⚠ |
| workspace-grill | 14 天内一次 | `workspace-grills/` 最新决策件日期 | >14 天 ⚠ |

锚缺失（某项找不到执行记录）= 如实标「无记录」暴露登记债，不静默跳过。看板只提醒不承载——各定期项的处理流在 workspace-ops 既有路由；知识库加固、同事库对比、维护仓库、阶段回顾为事件驱动（非定期），不进提醒。

**① 建议（最先输出，2–3 条）**：AI 判断的「现在最值得动什么」+ 一句为什么。判据：闸门积压量（多个任务中等同一动作）、静默时长（越等越沉）、解锁面（一个动作开几个任务）、批量机会（同走一个流程）。是建议不是结论，操作者可无视。顺延单不进建议（非当前行动面）；顺延到期组的开工确认可作为批量建议。

**② 你的闸门队列**：表 `| 动作 | 任务 | 状态 | 静默 |`——动作 = 给操作者的**动词**（审/裁决/确认/放行/定时机/取证）；任务名链接直达材料入口（review / README / CURRENT，按任务实际交付物选最该看的那个）；**排序 = AI 建议序**（判断：解锁密度/一句话闸门聚集/新鲜度），允许与 ③ 不一致——②是行动序，③是稳定地图。

**③ 全任务图**：表 `| 类别 | 任务 | 状态 | 卡点 | 下一步 | 未动 |`——类别列显示工作流标签；**每任务一行**；**已完成不显示**（不占行、不进 ①②④ 与静默统计，仅头行计数留笔数）。

- **排序确定性规则（跨会话稳定）**：状态生命周期序（进行中 → 编码中 → 审核中 → 验证中，与开工汇报/未归档清单同口径）→ 静默降序（老的在前，压力可见）→ 目录名稳定序兜底——行动维度已由 ② 闸门队列单独承载，③ 是纯状态地图；卡点、类别两列均纯属性不参与排序（卡点=你的行仍加粗，状态块内一眼弹出）；下一步保留关键子句不腰斩；禁止把任何组压缩成斜杠名单（那是目录不是信息）。
- 顺延单不占行（操作者裁决）：表后一行计数「另有顺延下迭代 N 张（问则列）」；顺延到期组（blocker 顺延语义 + `sprint-version` 已达 WORKFLOW 当前值）在表后单列小节展开。

**④ 风险雷达**：定期项风险（仅 ⚠/到期边缘 项，规格见「定期项提醒」）、静默超期明细（含在谁手里）、未提交堆积（数量 + 主题批归属 + 批次规模提示）、对外欠账开放数（评论/回复/对账类承诺未发）、孤儿目录、next 为空。

**尾注**：单卡详情「卡 X」（next/blocker 全文 + 最近一条进展 + 目录入口；顺延单同此，问即展开）｜顺延批展开「下迭代」／「顺延单」｜变化「X 自 DD 变了什么」走 git log｜续接「续 X」。

## 五、边界与例外

- **孤儿目录**（有目录无 CURRENT）：雷达列出标 ⚠，不静默漏。
- **next 为空**：显示 `(无 next)`——暴露文档债，不掩盖。
- **同名歧义**：带根前缀区分（`story/99999` vs `research/99999`）。
- **建议的边界**：①段只建议排序与批量，不代做裁决——闸门内容（审什么/裁什么）必须由操作者亲自判断。
- **本 skill 不触发立项**：看板是视图；从看板续接任务走既有开工流。

## 六、分工边界

- **开工汇报**（[WORKFLOW §2.1](../../../WORKFLOW.md)）= 同配方简版（列活跃任务 + 续接），无分诊排版——两者共用 §二 配方，禁另起炉灶。
- **workspace-check** = 门禁（INDEX 对齐 / 状态不变量），看板发现的疑似问题与其分区重叠时只标注、不代跑修复。
