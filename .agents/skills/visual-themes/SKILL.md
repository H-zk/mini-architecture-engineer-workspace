# visual-themes（HTML 可视化多主题库）

> 给本工作区的 HTML 可视化产物（show-me 报告、任务全景图、回顾/成长可视化等）提供**可切换的多套主题**。预设制设计（named presets × 场景映射）；vendor show-me 本体不改，本 skill 是**明示召唤的主题增强层**。

## 1. 边界（最高优先级）

1. **默认不用**：非操作者明示**绝不加载**，也绝不主动提议「要不要用主题」。常规可视化请求走 show-me 原流程（样式现场按内容定）。判断标准：消息中出现本 skill 名、「主题」字样修饰可视化产物、或要求改造既有 HTML 的视觉风格——三者皆无 = 不加载（主题由 show-me 现场定）。
2. **与 show-me 的关系**：本 skill 只提供主题定义；「生成什么内容、什么形态（diagram/infographic/slide deck）」仍由 show-me 承载。明示主题时两者配对：show-me 管内容与结构，本 skill 管视觉 token。
3. **产物边界完全继承 show-me**：自包含单文件、只落 `temp/`（操作者明示要求留档的产物可进任务目录）、**任何情况不自动打开浏览器**、只报路径由操作者自访。
4. **不触碰 Mermaid 真源层**：文档与设计里的流程/架构图以 Mermaid 代码块为真源；本 skill 只作用于 HTML 工件层。

## 2. 主题目录（选定时读对应 references/ 文件）

| 主题 | 明暗 | 气质一句话 | 适用场景 |
| ---- | ---- | ---------- | -------- |
| `classic` | 浅 | 中性净版、克制专业 | 默认讲解/评审报告（现状审美的 token 化，打印友好） |
| `dark` | 深 | 深色科技、高对比 | 屏幕阅读的技术图、链路/架构讲解 |
| `blueprint` | 深 | 蓝图网格、线框风 | 架构图、拓扑图、组件关系图 |
| `editorial` | 浅 | 暖纸出版、衬线标题 | 叙事型报告、阶段回顾、成长报告 |
| `terminal` | 深 | 终端绿字、等宽 | CLI/日志/CASE 排查讲解、代码链路 |

- 读法：`references/<主题名>.md`（如 `references/blueprint.md`）——**只读选中的那一篇**，不整目录通读。
- 操作者未指定具体主题、只说「用主题」/「换个主题」→ 展示上表让操作者选，不自作主张。

## 3. 使用协议

1. **新建产物**：show-me 定内容与结构 → 读选中主题文件 → 把 tokens 的 CSS 变量块注入 `<style>` 的 `:root` → 组件样式全部消费变量（`var(--bg)` 等），**禁止把色值散落硬编码**（否则换主题失效）。
2. **既有 HTML 换主题**：读原文件 → 只替换 `:root` 变量块与个别主题强相关样式（如网格底纹、字体栈），**不动内容结构、不重写正文** → 改完仍是自包含单文件。
3. **一产物一主题**：每件产物固定一套主题；不做页内明暗切换开关（有需求再按 viewer 思路扩展）。

## 4. 应用规范（所有主题共同约束）

- **零外链**：字体只用系统字体栈（各主题文件已定义，含 Windows/macOS 中文回退），禁 Google Fonts/CDN/iconfont 外链（外链致弱网/受限环境回退，「自包含」破功）。图标用内联 SVG 或 Unicode 符号。
- **单文件自包含**：CSS/JS 全内联，无外部资源引用。
- **图表色板**：序列图/分类着色用主题文件定义的 palette（保对比与色盲可辨），不自由发挥。
- **响应式**：桌面与移动可读（show-me 既有要求，随主题不变）。

## 5. 扩展协议（新增主题）

1. `references/` 按模板新增 `<主题名>.md`（tokens CSS 块 + 字体栈 + 组件要点 + 图表色板 + 注意事项）；
2. 本文件目录表加一行（明暗/气质/场景三列说清）；
3. 主题文件 frontmatter 标 `created-at`/`updated-at`；新主题色值有来源的注明来源。
