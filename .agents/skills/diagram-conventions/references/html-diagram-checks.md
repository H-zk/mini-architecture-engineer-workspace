# 手绘 HTML 图渲染细则与校验三查

> 适用 = 单文件零依赖 HTML（show-me 类）手工画时序图/流程图、要「控到像素」；要交互/复杂图直接走 Mermaid。心法：**零自动摆放、零悬浮标签、零运行时测量**——几何全用固定百分比/伪元素表达，长文本不许换行抢高度。

## 时序图

1. 生命线固定百分比定泳道中心（如 10/30/50/70/90）+ 每消息一固定高度行（如 56px、超高 `.tall` 如 64px），线/箭头容器百分比定位（如 `left:30%;width:20%`）——禁 grid 自动摆放（错行叠行）。
2. 标签**中点定位 + nowrap**（定宽区间定位长文换行、超行高即叠压相邻消息）：`left:<mid>%` + `transform:translate(-50%,-50%)` + `white-space:nowrap`，恒两行（主文+副文 block）；超长副文手动 `<br>` + 该行升 `.tall`；旧稿迁移 = `left:X%;width:Y%` 批量替换 `left:<X+Y/2>%`（可 replace_all）。
3. 箭头纯 CSS 三角 + 负 margin 回拉（`▶` 字符受字体基线影响不齐、越线约 8px），尖端恰落目标生命线；标签/注释**实底背景**（半透明被生命线穿透），底部注释有背景 = 生命线视觉终止该行、右侧留 padding 让位悬浮按钮。

## 流程图

1. 分支连线 = 伪元素轨线（零 JS 零测量）：决策框底中点垂线→横轨→各列中心垂线；**列 `gap:0` + 列内 `padding:0 13px`**（有 gap 横轨断开），首列 `::before` 用 border-top+border-left 画「右半轨+左垂线」、末列镜像，两段半轨列缘相接成整轨；垂线带 `margin-top` 留白 + 伪元素负偏移入带绘制（不留 DOM 痕迹）。
2. 合流 `.join` + `align-items:stretch` 两列底对齐，列底半轨汇成横轨贴容器底缘（`padding-bottom` 让位）直接接箭杆，无需中点垂线；连线色收敛 CSS 变量（如 `--flowline`）深浅主题一处换肤。
3. **对称呼吸间距定式**（0 间距贴框即视觉噪声、上贴下松是返工根因）：分叉带总高如 26px = 判断框→轨 12px + 轨→分支标签 12px，合流垂线同规。

## 结构校验三查（改完必跑）

与 `.tools/html-render-audit.mjs`（CDP 几何审计）分工：**几何/溢出/对比度类走该工具**；本三查管**结构正确性**（手改大 HTML 防结构撕裂），Python 正则/栈解析：

1. div 开闭平衡：`len(re.findall(r'<div\b', html)) == len(re.findall(r'</div>', html))`。
2. 逐消息线核对：线段终点 = 箭头落点、标签 `left` = 线段中点、自调用盒 `left` 落生命线上（泳道中心值）。
3. 栈解析核对每个分叉恰好双列（`:first-child/:last-child` 半轨方案的前提）。

三查属自律项（产物多在 temp/，无常驻机检钩子）；手绘撕裂返工若复发计数 ≥2，按毕业计数通道升格为脚本。
