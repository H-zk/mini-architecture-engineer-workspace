# diagram-conventions（产图约定）

> 分工口径（真源 = AGENTS「编辑文档 · design 图表用 Mermaid」）：**Mermaid = 可维护机制图**（markdown 真源层）；**SVG + lint = 出版级一次性精确图**；show-me HTML = 轻量梳理层。总原则：**内容自由、渲染守约**——约定只管排版与可读性，不管内容取舍；信息密度不因约定截断（需要密度就上详版，不删事实凑简洁）。

## 一、选型判据（先定读者问题，再选模型）

> 视图级前置：交付物不止单张图（看板/报告/仪表盘/HTML 汇总页）时，设计冻结前先过 [references/view-jobs-first.md](./references/view-jobs-first.md) 的 jobs-to-be-done 门禁——先定「操作者拿它做哪几个动作」，再进本节图级选型。

1. 先回答「读者看这张图要回答什么问题」，再选模型——不为画而画，**不因输出是图就默认用 SVG**。
2. 八型模型按问题选：topology（组件连接）/ sequence（消息时序）/ process（步骤分支）/ state（状态转移）/ hierarchy（包含归属）/ timeline（随时间变化）/ matrix（重复二维关系）/ quantitative（量级对比）。
3. 同义可承载时用更简的模型；决定**什么必须同屏可见、什么按需展开**；复杂画布放受控滚动区。

## 二、SVG 绘图约定（渲染守约）

- **CJK 字体栈**：`-apple-system, "Segoe UI", "PingFang SC", "Hiragino Sans GB", "Microsoft YaHei", sans-serif`；中文标签宽度按全角预算。
- **间距**：兄弟/相邻框 ≥25px（推荐 25–30）；文字与线 10–20px；图例置图外（底部或侧边），不压内容区。
- **居中**：内容居中（`左右边距 = (viewBox 宽 − 内容宽) / 2`）；**标题对齐内容中心**（非画布中心——内容不对称时两者不同）；事后发现不对称用 `<g transform="translate(dx,dy)">` 整体平移。
- **无重叠**：文字不压框线；线不穿框（箭头终止于框除外）；线标签放线侧不骑线。
- **首过自查**：生成后走一遍检查清单再交付——标签碰撞、裁剪（viewBox 边距）、溢出、对齐、色盲可辨（含义不单靠颜色，格内加文字）。
- 色彩 ≤4 族；零外链（字体/图标全本地，图标用内联 SVG 或 Unicode）。

## 三、手绘 HTML 图表约定（渲染守约）

> 适用 = 单文件零依赖 HTML（show-me 类）手工画时序图/流程图、要「控到像素」；要交互/复杂图直接走 Mermaid（本节不管）。心法：**零自动摆放、零悬浮标签、零运行时测量**——几何全用固定百分比/伪元素表达，长文本不许换行抢高度（换行抢高度 = 叠压返工根源）。像素定式与结构校验三查见 [references/html-diagram-checks.md](./references/html-diagram-checks.md)。

- **时序图**：生命线固定百分比定泳道 + 每消息一固定高度行（超高行升 `.tall`）——禁 grid 自动摆放（错行叠行）；标签**中点定位 + nowrap 自适应宽**（定宽区间定位长文换行必叠压相邻消息）；箭头纯 CSS 三角负 margin 回拉尖端落生命线（`▶` 字符基线不齐）；标签/注释实底背景（半透明被生命线穿透）。
- **流程图**：分支连线用伪元素轨线（零 JS 零测量）——列 `gap:0` 改列内 padding（有 gap 横轨断开），首末列半轨列缘相接成横轨；合流列 `align-items:stretch` 底对齐汇轨；轨线与区块**两侧对称呼吸间距**（上贴下松即视觉噪声）；连线色收敛 CSS 变量一处换肤。

## 四、svg-lint 门禁（工具未接入，纪律先行）

- 当前 SVG 产物过 §二「首过自查」清单交付；后续若接入 svg-lint 机检（候选上游 bybit-exchange/svg-diagram@main，MIT，包装为 `.tools/` 脚本），门禁纪律 = 修到 0 error、布局语义所需的残留项可记录保留、每次运行报上游版本。
- **降级纪律（lint 是门禁不是交付物）**：lint 工具克隆/运行失败**不阻断产图、不反复重试**，SVG 照常交付，但必须在会话中报备「本次 lint 未跑」。

## 五、交付检查

- **富产物两步交付**：富 HTML 产物（手册 / 视图 / 对比页）先交结构骨架（章节、表列、卡片清单）确认，再出视觉全量；全量交付前过**程序化复验**——无头 DOM 断言自查（横向溢出 + 已知缺陷类的计算样式断言，如深底区文字对比度、徽章截断，可用 `.tools/html-render-audit.mjs`），不消耗图片上下文；发现问题按缺陷类回归兄弟产物；图片工具仅在操作者报告可视问题后启用（缺陷定位用）；权重记当值任务。
- **数字必有出处**：报告/视图终稿逐数回指来源一遍——每个数字答得上「哪来的」；叙事需要但没有的数，补测或改定性表述，不造中间值。
- 单自包含 HTML（SVG 内联或同目录相对引用）；无构建步骤、无外部服务。
- 宽窄双宽度检查；键盘可达（交互态）；`prefers-reduced-motion` 兼容（若有动效）。
- 随产物报告：选了什么模型、做了哪些简化/假设。
