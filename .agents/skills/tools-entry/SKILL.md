# tools-entry

> 工作区小工具（`.tools/` 脚本）的**会话入口登记簿**。操作者不直接执行脚本，经会话关键词触发；本 skill 承载「触发词 → 命令 → 授权档位」映射与通用执行协议。工具行为与脚本位置真源 = `.tools/INDEX.md`（位置变动不改本文，防硬绑漂移）。

## 通用协议（所有登记工具共用）

- **关键词命中才触发**，不主动建议；相邻话题（如普通本地 `git merge`、手工对账）不误触发。
- **脚本位置以 `.tools/INDEX.md` 登记为准**。
- **授权两档**：
  - 只读命令（dry-run / 对账类）：AI 默认可执行；
  - 写操作（`--apply` 类）：须操作者**当次明确授权**——历史授权不延续、dry-run 结果不构成授权。AI 在非交互 shell 完成不了脚本的交互确认，**以对话中的明确授权替代**，写命令统一加 `--yes`。
- **密钥由脚本内置 loader 从 `.env.local` 自动加载**；AI 不加载、不展开、不打印任何密钥变量。
- 脚本安全类致命错误（TLS / 认证 / 限流 / 5xx）= 全局致命：立即停止并原样报告，不重试、不降级、不吞。
- 失败只报告（汇总区清单原样呈现），由操作者决定是否重试；AI 不自动重跑。

## 已登记工具

### context-usage（会话上下文占用探针）

- **触发词**：上下文占用 / context usage / 上下文探针 / rollout 占用
- **命令**：`python .tools/context-usage.py`（只读档位，AI 默认可执行；`--breakdown` 底座归因粗估）
- **汇报要求**：报告真实上下文占用 + 逐调用增长轨迹；**不打印会话正文**（内容不外显）；rollout 路径变动报错即修，不臆测路径。
- **用途**：长会话接近上下文上限时量化占用、定位增长最快调用，辅助决策「收口 / 换会话 / 拆任务」。

## 新工具登记约定

- **追加一节**：小节名 = 工具名，内容 = 触发词 + 命令 + 授权档位 + 特有约束；同步更新本文 frontmatter `triggers` 与 `.agents/skills/INDEX.md` 触发词列。
- **准入判断**：关键词命中即可执行、无需 Lifecycle/门禁/产物的小脚本才入本登记簿；复杂到需要状态机、DoD、任务产物的工具应独立成 skill（按 skills INDEX 的执行流分档）。
- 登记样例（授权两档 + 参数速查表的形态）：每节含触发语、协议步骤（dry-run 默认可执行 → 授权后 `--apply --yes`）、参数速查表、汇报要求。
