# report.md 骨架（外部文章分析报告）

> 产 report.md 前必读。frontmatter 必带 `锚点: <链接>（读后定性：原文｜忠实摘要｜有损摘要｜营销向；材料不可核部分显式标注）`、`分析深度: 快扫｜标准｜深度`（标准 = 直读分析、深度 = 深读轮后）、`分类置信度: 高｜中｜低`（文章定位判断的置信度，低置信须写明存疑点）——防「浅读硬下深判」。通用字段（分析深度 / 分类置信度 / 证据三级标注 / 重分析触发条件）继承 [`skill-fit-eval/references/report-skeleton.md`](../../skill-fit-eval/references/report-skeleton.md)，此处按文章对象收窄。

## 标题与结论速览

- 标题：`# <主题> 文章分析：<一句话主结论>`
- 首节**结论速览 / 结论先行**：每篇一行定性 + 三层结论汇总一行——读者不读全文也能裁决。

## 章节骨架（按对象可裁剪，顺序不变）

| # | 章节 | 要点 |
| ---- | ---- | ---- |
| 一 | 逐篇分析（每篇三段） | **方法论骨架**（引原文关键句，[原文明示] 标注）→ **对照本区**（已覆盖 / 已覆盖·更细 / 同构 / 真空隙 / 撞车 / 不适配，逐条映射并点名本区机制 / skill / BACKLOG 行）→ **三层结论**（✅ 即用 / 🟡 固化候选 / 参照） |

## 变体章节（点名才加）

- **辩证版**（操作者点名辩证）：正题（印证清单）→ 反题（盲区与不适配，具体论据不止态度）→ 合题（真空隙与建议）三节，插在逐篇之后、综合层之前。
- **深读轮分文件**：`report-deep-synthesis.md`（叙事者利益分析 + 跨源定律核对 + 隐性风险），report.md 加指针。
- **多主题分报**：每主题 `report-<name>.md` + 综合层 `report.md`，主报告收敛为摘要 + 指针。
