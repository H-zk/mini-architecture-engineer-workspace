# report.md 骨架（单仓定向选型评估报告）

> 产 report.md 前必读。frontmatter 必带 `锚点: <owner/repo>@<tag 或 main@hash>（锚定日期；无 tag 偏差留痕）`、`分析深度: 快扫｜标准｜深度`（快扫 = 初判轮产物、标准 = 初判 + 部分深读、深度 = 深析轮后）、`分类置信度: 高｜中｜低`（对象定位判断的置信度，低置信须写明存疑点）——防「浅读硬下深判」。

## 标题与结论速览

- 标题：`# <skill 名> 单仓定向选型评估：<❌/✅ 主判定一句话>`
- 首节**结论速览**：三层结论各一行 + 主判定理由一句话——结论先行，读者不读全文也能裁决。

## 证据来源三级标注

凡引用对象的观点、规则、示例，标注来源层级：**[原文明示]**（原文可溯，引关键句）/ **[约束推导]**（由原文约束合理推出）/ **[分析补充]**（本区分析推断）——推断不得伪装原文，材料不足写「材料不足」不硬编。

## 分工与变体

- **深析分文件**：`analysis-<skill>.md` 管本体质量与拆件清单，`report.md` 管适配判定——两文首互相声明分工。
- **多对象**：每对象一份 `report-<name>.md`（本骨架不变）+ 综合层 `report.md`（交叉对照 + 综合方案）；主报告 §3/§4 收敛为摘要 + 指针。
- **实测分文件**：`trial-<主题>.md` 记录实测设计、原始读感 / 数据与回流结论。

## 判据速查（引用不展开）

三关细则、三层结论结构、质量 / 热度 / 适配正交、同病两层药方、器官型错配、常驻注入 vs 渐进披露、证据形态定档——引用时写判据名（出处经 `exps/INDEX.md` 检索），不在报告里复写演化史。
