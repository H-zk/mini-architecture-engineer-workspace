# /knowledge-create

根据 AGENTS.md `## 知识库` 章节声明的目录结构，初始化知识库或创建指定主文档。

## 参数

- `$ARGUMENTS`（可选）：指定要创建的文档编号或文件名（如 `05` 或 `05-user-management.md`）。不传则初始化所有缺失的主文档。

## 执行步骤

### 1. 读取 AGENTS.md 中的知识库配置

从 `AGENTS.md` 的 `## 知识库 → ### 目录结构` 代码块中解析主文档列表，得到每个文档的：

- 编号（如 `00`、`01`）
- 文件名（如 `00-project-overview.md`）
- 简要说明

### 2. 确定创建范围

- 如果 `$ARGUMENTS` 指定了编号或文件名，只创建该文档
- 如果 `$ARGUMENTS` 为空，扫描 `notes/` 目录，找出所有缺失的主文档，逐一创建

对于已存在的文档：

- 已存在且非空（行数 > 10）→ 跳过，提示"文档已存在，如需更新请使用 `/knowledge-improve`"
- 已存在但几乎为空（行数 ≤ 10）→ 视为缺失，覆盖生成

### 3. 创建目录结构

确保 `notes/` 和 `notes/temp/` 目录存在。

### 4. 分析源码并生成文档

对每个需要创建的主文档：

1. **根据文档说明确定探索范围**：从 AGENTS.md 声明的简要说明推断该文档覆盖的业务域
2. **探索相关源码**：
   - 路由/控制器模块
   - 状态管理/数据层模块
   - 页面/视图组件
   - API/服务层
   - 工具函数和公共逻辑
3. **按模板格式编写文档**：先读取 skill 的 `references/doc-template.md` 获取最新模板，包含：
   - 概述（2-3 句话定位）
   - 关键文件表格（文件路径 + 职责）
   - 业务流程（触发条件 → 核心步骤 → 结果）
   - 数据模型（关键字段）
   - 注意事项（开发踩坑点）
4. **写入文件**到 `notes/{编号}-{名称}.md`

### 5. 输出结果

列出本次创建的文档清单，以及跳过的已有文档。

## 示例

```bash
/knowledge-create              # 初始化所有缺失的主文档
/knowledge-create 05           # 只创建 05-user-management.md
/knowledge-create 00-project-overview.md  # 指定完整文件名
```
